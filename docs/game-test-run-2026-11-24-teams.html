Game test run, 24 November: team files

What a team file can change besides the squad: the crest, the short name and stadium name, and the name in a licensed and an unlicensed competition. Record each answer here as you go; it is saved straight away and I read it from here.

Connecting…

Before you start

  1. Copy the WEPES folder from D:\PES21-local-test\final-exports\game-tests-teams to the USB drive.
  2. Edit → Data Management → Import/Export → Import Team. Tick all 6 files and import, with Apply player and squad data on.
  3. No images to import: the two crests used (Liverpool FC's and Chelsea FC's) are already in the game from the option file.

Six teams no earlier test touched. Each file is the option file's own file for that team with only the fields named below changed, so nothing else about the team moves, and the six can be imported together. Nothing needs undoing.

A. Crests

Question 26: can a team file change a team's emblem, in a licensed league and in an unlicensed one?

Each team is given another club's crest that is already in the game, the way test 59 gave Brøndby Arsenal's. Look at the crest on the team select screen and in a match.

B. Short name and stadium name

Question 17: besides the players, what else of a licensed team can a file change?

Both teams keep their name and crest; only the 3-letter short name and the stadium name change. Look at the short name on the scoreboard in a match, and the stadium name before kick-off or in Edit.

C. Names, by competition

Does a team's name change by its competition (licensed leagues keep the game's names, the rest take the file's), and are AC Milan and Shakhtar Donetsk ("name may be fixed") fixed?

Only the name changes. By the rule you gave (one answer per competition), AC MILAN stays (Serie A is licensed) and SHAKHTAR DONETSK becomes T80 (Other Teams (Europe) took new names in tests 39 and 60).
