A. In the game's own Edit

Question 13c (part A): which of the game's own leagues does the game's Edit let you rename?

  1. Edit → Competitions. For each league below, try to change its name. Note whether the name field can be changed and saved.
  2. If Edit → Data Management → Export lets you export a competition, export each league you could rename to the USB drive and type the file's name in the last column. Its code and slot are inside it, which ends the guessing for that league.

B. Competition files on guessed codes and slots

Question 13c (part B): can a competition file give one of the game's own leagues a new title and logo, and which code and slot does each league have?

A competition file changes a competition only when its code and slot are that competition's own pair (tests 21 to 23): a wrong pair whose code exists is accepted and does nothing. The game's own leagues have no file, so their pairs are worked out from the 53 pairs the option file has: codes and slots rise together in the game's order. Each file is the Premier League's file with only the code, slot and title changed, so its title names its own pair (T65 CODE 20 SLOT 12) and its logo is the Premier League's. Whatever competition shows a T title tells us that league's pair.

  1. Copy the WEPES folder from D:\PES21-local-test\final-exports\game-tests-leagues to the USB drive.
  2. Edit → Data Management → Import/Export → Import Competition. Tick all 15 files and import. If a refusal stops the rest, import them one at a time.
  3. For each file: accepted or refused (with the message), and which competition, if any, now shows its T title. Look at that competition's logo too.

Context: test 24 (22 November) wrote code 18 on slot 10 and was refused ("either competition data doesn't exist or editing is prohibited"). By the game's order that is almost certainly Serie A's own pair, so a refusal here may mean editing prohibited (a licensed league), not a wrong guess. A league that refuses in part A and refuses here is likely locked.
