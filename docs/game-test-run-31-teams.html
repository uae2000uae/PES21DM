Number of teams: can a competition be given more teams than it has, up to 31, with team files of existing teams?

  1. Copy the WEPES folder from D:\PES21-local-test\final-exports\game-tests-31-teams to the USB drive. It holds 366 files, named test88_01_… to test115_17_…: the test number is the competition, the second number the team.
  2. Import them one at a time with Import Team, in name order.
  3. After each test (all its files imported), note whether any team was added to that competition, and if so its total number of teams.

The teams: the four ADNOC Pro League clubs that have codes of their own (AL AIN, AL WAHDA, SHABAB AL AHLI DUBAI, SHARJAH), then clubs from Other Teams (Europe) and Other Teams (Latin America); for ADNOC Pro League itself, BRI Super League clubs. No team used in tests 1 to 87 is among them. Each file is the option file's own file for that team, unchanged, so the same team's file is identical in every competition: the competition it is meant for is in the file name only.
